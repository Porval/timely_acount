# 账号模块开发说明

## 当前已提供

- 独立 Git 仓库内的 Node.js 工程配置。
- `src/index.js`：启动服务，读取 `HOST` 与 `PORT`。
- `src/server.js`：`createApp()` 工厂，便于接口测试及后续注入业务服务。
- `GET /api/health`：服务状态检查；未知路由返回 JSON 404。
- 使用 Node.js 内置测试运行器，不依赖外部测试框架。

## 业务范围待确认

“账号系统”可能指及时达账号管理、用户注册登录，或平台账号资料保存。目前未预设业务字段、接入已有账号接口，也未创建真实账号。

后续实现时，建议将路由、业务逻辑和存储分开：在 `src/modules/accounts/` 放账号模块，在 `src/server.js` 挂载接口。在业务范围确定后选择合适的数据库与前端技术。

若是及时达账号管理，先明确账号标识、所属门店、启停状态及已有系统接口；若是用户注册登录，先明确登录方式、用户角色和会话管理；若是平台账号资料保存，先明确需要保存哪些字段以及敏感字段的保护方式。

## 开发约定

- 禁止在源码及 Git 中保存真实密码、令牌或账号数据。
- `.env` 和 `data/` 已加入 `.gitignore`。
- 增加接口时，同时更新 README 中的接口说明，并针对实际行为添加测试。
- 在独立模块开发，确认接入方式后再修改周边项目。
